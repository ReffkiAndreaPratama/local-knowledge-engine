# Code of conduct

## Our commitment

This project should be a place where people can report a bug, ask a basic
question, or disagree about a design decision without being mocked. We welcome
contributors regardless of experience, background, identity or preferred stack.

## Expected behaviour

- Be direct about code and kind about people. Critique the change, not the person.
- Assume good faith. Ask a clarifying question before concluding someone was
  careless.
- Keep discussion on topic. Feature requests and long design debates belong in
  issues, not in unrelated pull requests.
- Respect privacy. Do not post someone else's documents, logs, paths, keys or
  personal information. Redact before pasting.
- Accept a maintainer's decision to keep the MVP small. "Out of scope for now" is
  a valid answer.

## Unacceptable behaviour

- Harassment, insults, threats, or discriminatory comments of any kind.
- Sexualised language or imagery, and unwelcome attention.
- Publishing private information without permission.
- Deliberately derailing threads, spamming, or repeatedly ignoring maintainer
  guidance.
- Submitting code you did not write without attribution, or code whose licence is
  incompatible with this project.

## Scope

This applies to issues, pull requests, discussions, commit messages, and any space
where someone is representing the project.

## Enforcement

Maintainers may edit or delete comments, close threads, reject contributions, or
block accounts. Enforcement should be proportional: a correction first, then a
warning, then a temporary or permanent ban for repeated or severe behaviour.

If you experience or witness unacceptable behaviour, contact the maintainer
privately (see the repository profile) rather than replying in the thread. Reports
will be handled as confidentially as practical. Retaliation against someone who
reports a concern is itself a violation.
